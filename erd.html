상담 만족도 ERD

csat_survey · support_tickets · agents · customers — 키와 상담 만족도에 쓰는 컬럼만 표시

erDiagram
    customers ||--o{ support_tickets : "고객 1명이 문의 여러 건"
    agents ||--o{ support_tickets : "상담원 1명이 문의 여러 건"
    support_tickets ||--o| csat_survey : "문의 1건에 설문 0~1건"
    customers ||--o{ csat_survey : "고객 1명이 설문 여러 건"

    customers {
        string customer_id PK "고객 ID"
        string plan_type "요금제"
    }
    agents {
        string agent_id PK "상담원 ID"
        string team "소속 팀"
    }
    support_tickets {
        string ticket_id PK "문의 ID"
        string customer_id FK "문의한 고객"
        string agent_id FK "담당 상담원"
        date created_date "문의 접수일"
    }
    csat_survey {
        string survey_id PK "설문 ID"
        string ticket_id FK "설문 대상 문의"
        string customer_id FK "응답 고객"
        date survey_date "설문일"
        int csat "상담 만족도 점수(1~5)"
    }

테이블마다 한 행이 뜻하는 것

테이블한 행 =
csat_survey상담 문의 1건에 대해 고객이 남긴 만족도 설문 응답 1건 (문의 1건당 최대 1건)
support_tickets고객이 접수해 상담원 1명이 맡은 상담 문의 1건
agents상담원 1명
customers고객 1명
